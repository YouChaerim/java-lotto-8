# java-lotto-precourse

## 🚀 기능 목록

### ⌨️ 입력 기능
-   로또 구입 금액을 입력받는다. (안내 문구: `구입금액을 입력해 주세요.`)
-   당첨 번호 6개를 쉼표(`,`)로 구분하여 입력받는다. (안내 문구: `당첨 번호를 입력해 주세요.`)
-   보너스 번호 1개를 입력받는다. (안내 문구: `보너스 번호를 입력해 주세요.`)

### ⚙️ 핵심 로직 및 도메인 기능
-   1,000원 단위로 로또를 구매하여, 구매한 개수만큼 로또(`Lotto`) 객체를 생성한다.
-   로또 번호는 1~45 사이의 중복되지 않는 6개의 숫자로 생성한다.
-   발행된 `Lotto` 객체들을 리스트로 관리한다.
-   입력받은 당첨 번호 6개와 보너스 번호 1개를 `WinningLotto`(가칭) 객체로 관리한다.
-   구매한 모든 로또를 당첨 번호와 비교하여 당첨 등수(Enum)를 계산한다.
    -   1등: 6개 일치
    -   2등: 5개 일치 + 보너스 번호 일치
    -   3등: 5개 일치
    -   4등: 4개 일치
    -   5등: 3개 일치
-   총 구매 금액 대비 당첨금 총액을 바탕으로 수익률을 계산한다. (소수점 둘째 자리에서 반올림)

### 🖥️ 출력 기능
-   구매한 로또 개수를 출력한다. (예: `8개를 구매했습니다.`)
-   구매한 로또 번호 목록을 오름차순으로 정렬하여 모두 출력한다.
-   `당첨 통계`와 `---` 구분선을 출력한다.
-   5등부터 1등까지 각 등수별 당첨 개수를 형식에 맞게 출력한다.
-   최종 수익률을 형식에 맞게 출력한다. (예: `총 수익률은 62.5%입니다.`)

## ⚠️ 예외 처리
-   `IllegalArgumentException` 발생 시, `[ERROR]`로 시작하는 메시지를 출력하고, **해당 입력부터 다시 받는다.**
-   구입 금액이 1,000원 단위가 아닐 경우
-   구입 금액이 1,000원 미만(0 또는 음수)일 경우
-   구입 금액이 숫자가 아닐 경우
-   당첨 번호가 1~45 범위의 숫자가 아닐 경우
-   당첨 번호에 중복된 숫자가 있을 경우
-   당첨 번호가 6개가 아닐 경우
-   당첨 번호가 숫자가 아닐 경우
-   보너스 번호가 1~45 범위의 숫자가 아닐 경우
-   보너스 번호가 숫자가 아닐 경우
-   보너스 번호가 당첨 번호와 중복될 경우
